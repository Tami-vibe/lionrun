# Review Desk

Saved plan. Do not build this yet. Finish the website maker first.

The Review Desk is an add-on. Turn it on when a shop goes live. A downloaded HTML page and a WordPress site both call the same desk. The desk is the only place that stores real reviews.

## What a visitor sees

The public page shows the name, the stars, the words, and a small “Verified purchase” mark. It never shows the email or the receipt.

If that email already has a photo on the desk, the circle shows the photo. If it does not, the circle shows the first letters of the first and last name. The background color comes from the name, so it stays the same on every visit.

The website maker keeps labeled samples. The first verified review replaces the samples.

## Who may review

A person can review only after a real payment. The shop’s checkout, or the receipt the shop already gives, creates a one-time code. The code is tied to that customer’s email, the date, and the amount. The code works once. Then it expires. The same email cannot reuse it.

The live form asks for a name, an email, that code, a star rating, and the words. The desk checks that the code matches a real receipt and has not been used. If it matches, the review is saved. If it does not, nothing is published.

The shop owner still gets a yes-or-no switch. A rude but real customer does not have to appear.

## How this stays honest

A blockchain is not required. A chain can store a lie forever. It cannot tell you the person paid.

Truth comes from the receipt. The desk saves each match in a log. You can add to that log. You cannot quietly rewrite it. That log is the truth record.

Codes come from a payment record. Staff cannot type a fake code into a box and call it proof.

People can still copy the words on the page. That cannot be stopped. The email, the code, and the payment match stay on the desk.

## Why it works on any domain

The exported site only gets a public tag that names the shop. The form and the review list call the desk over https. The HTML download and the WordPress add-on use that same form and that same desk, so every domain looks like the site that was built.
